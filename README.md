# Auth Management Platform

Build a GoTrue operator dashboard first, then a developer auth platform, using one shared GoTrue identity pool.

Start at the [documentation index](documentation/README.md) to find the authoritative document for each topic. Agent coding and delivery rules are in [AGENTS.md](AGENTS.md).

The initial operator backend is implemented in [apps/gotrue-admin-api](apps/gotrue-admin-api/README.md). Live database/auth verification awaits user setup; no frontend or platform backend is implemented. Local service setup and commands are documented in [infrastructure/local](infrastructure/local/README.md). Existing VM operational references live in [vm_infrastructure](vm_infrastructure/vm-infrastructure-reference-updated.md).
